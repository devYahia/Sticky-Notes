# Sticky Notes App

I built this notes app as a practice project after studying the Net Ninja Node.js crash course. It was a great way to get hands-on experience with MongoDB, Express, and Node.js — and it turned out to be a really good learning experience.

## The Task

Create a simple sticky notes application consisting of two pages:

1. A page with a form to add a new note
2. A page that displays all the notes, with a link to the other page

Using MongoDB to store the notes and EJS templates to render the views.

## Tech Stack

- Node.js
- Express
- MongoDB (Mongoose)
- EJS

## How to Run

```bash
npm install
node app.js
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.
